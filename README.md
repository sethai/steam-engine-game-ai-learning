# Steam Engine Survival

A small browser game about keeping an old steam machine alive as long as possible —
balance water and coal against a boiler that will overheat, stall, or explode if
you get it wrong.

Built as a learning project using [Claude Code](https://claude.com/product/claude-code).

See [`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md) for the full design and mechanics,
and [`CLAUDE.md`](CLAUDE.md) for project conventions and structure.

## Running locally
Open `src/index.html` in a browser, or serve the folder:
```
npx serve src
```
